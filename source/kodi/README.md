```sh

```

### ALKOFLIX SETTINGS ENTRIES

```xml
<settings>
	<setting id="provider.alkopaste">true</setting>
	<setting id="catalogue.alkopaste.enabled">true</setting>
	<setting id="ad.token">TOKEN_HERE</setting>
	<setting id="ad.enabled">true</setting>
</settings>
```
